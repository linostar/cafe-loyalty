# Add to Google Wallet badges

Google's official "Add to Google Wallet" badges (English and Arabic), unchanged from the SVG package linked in the
[Google Wallet brand guidelines](https://developers.google.com/wallet/generic/resources/brand-guidelines)
(`add-to-wallet-svg.zip`: `enUS_add_to_google_wallet_add-wallet-badge.svg`, `ar_add_to_google_wallet_add-wallet-badge.svg`).
The guidelines allow only these buttons, unaltered (no change to font, colour, radius or padding; resized only with
their ratio kept; at least 48 px high with 8 px of clear space). The web card embeds them as data URIs (its CSP allows
no other images). Google artwork, used under Google's brand guidelines; not covered by this repository's licence.
